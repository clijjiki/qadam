# Qadam — подготовка к ЕНТ и IELTS

Сайт для самостоятельной подготовки к ЕНТ (профиль **Математика + Информатика**) и **IELTS Academic**.
Теория, практика с разбором, интервальное повторение ошибок, пробные экзамены в формате ЕНТ-2026, словарь и модули IELTS, план на неделю и честный прогноз баллов.

Всё работает **без интернета и без установки**: чистый HTML/CSS/JavaScript, контент в JSON, прогресс в браузере (localStorage).

## Как запустить

Дважды кликни `start.bat` (нужен Python, он уже установлен) — откроется `http://127.0.0.1:8080/`.

Или из терминала:

```bash
python serve.py 8080
```

Открывать `index.html` двойным кликом **нельзя**: браузер запретит загрузку файлов контента.

## Что внутри

| Раздел | Что делает |
|---|---|
| **Сегодня** (`#/`) | прогноз ЕНТ из 140, миссии дня на 20–40 минут, серия дней, неделя |
| **ЕНТ** (`#/ubt`) | пять предметов, мастерство по темам, слабые темы, микс вопросов |
| **Тема** (`#/topic/:id`) | конспект с формулами (KaTeX), карточки, переход к практике |
| **Практика** (`#/practice/:id`) | 10 вопросов, мгновенный разбор, «почему другие неверны», работа над ошибками |
| **Повторение** (`#/practice?mode=review`) | очередь SRS: вопросы, в которых ошибался |
| **Пробники** (`#/exam`) | полный ЕНТ (120 заданий, 240 минут) и мини-пробник (45 минут), таймер, автосохранение, разбор |
| **IELTS** (`#/ielts`) | Reading с текстами, Listening с озвучкой, Writing с самопроверкой по критериям, Speaking с таймерами, словарь с SRS, грамматика |
| **План** (`#/plan`) | фазы до экзамена, неделя по дням, часы в неделю, смена в школе |
| **Статистика** (`#/stats`) | активность, точность, прогноз по предметам, таблица тем, бейджи |
| **Настройки** (`#/settings`) | профиль, тема оформления, экспорт и импорт прогресса, сброс |

### Как считается прогноз

- **Мастерство темы** = точность последних попыток × уверенность (сколько вопросов решено) × память (сколько дней прошло с последнего повторения).
- **Прогноз по предмету** = максимум баллов × (0,15 + 0,85 × средневзвешенное мастерство тем). Если есть пробники за последние 60 дней — прогноз усредняется с их результатом.
- **Баллы ЕНТ**: один ответ — 1 балл; несколько ответов и соответствие — 2 балла, при одной ошибке 1 балл, при двух и более 0. Штрафа за пустой ответ нет.
- **IELTS band** — среднее по навыкам, округление до 0,5. Writing и Speaking считаются по самооценке и помечены как самооценка.

## Как добавить новую тему

1. Открой `docs/CONTENT-SCHEMA.md` — это контракт: структура файла, типы вопросов, нормы по предметам.
2. Найди нужную тему в `scripts/topic-order.json` (там все 124 запланированные темы с id, названием и весом на экзамене).
3. Создай файл `content/<предмет>/<id>.json` по схеме.
4. Проверь: `python scripts/validate_content.py content/<предмет>/<id>.json` — должно быть `[OK]`.
5. Пересобери манифест: `python scripts/build_manifest.py`. В манифест попадают только темы, у которых есть файл, — недописанные не ломают сайт.
6. Обнови страницу в браузере.

Сейчас готово 9 тем и 125 вопросов, остальные 115 тем ждут контента.

## Проверки

```bash
python scripts/check_imports.py
```

```bash
python scripts/validate_content.py
```

Тесты движка (баллы, SRS, мастерство, markdown, даты, роутер) открываются в браузере: `http://127.0.0.1:8080/tests/`. Заголовок вкладки покажет `OK` или `FAIL: n`.

## Структура

```
index.html            оболочка
serve.py, start.bat   локальный сервер
assets/css/           дизайн-система и стили страниц
src/core/             логика: store, content, mastery, srs, scoring, exam, plan, stats, markdown
src/ui/               компоненты: layout, quiz, charts, modal, toast, player
src/pages/            по одному модулю на маршрут
content/              JSON с темами + manifest.json
scripts/              build_manifest.py, validate_content.py, check_imports.py
docs/                 CONTENT-SCHEMA.md, research/ (спецификации ЕНТ и IELTS), design/
tests/                тесты движка в браузере
```

## Прогресс и данные

Прогресс хранится только в браузере (ключ `qadam.v1`). Раз в месяц делай экспорт в настройках — файл можно перенести на другое устройство через импорт.

# Схема контента Qadam (контракт для авторов тем)

Каждая тема — один JSON-файл по пути из `content/manifest.json` (`content/<subject>/<id>.json`).
Сайт статический: **никаких картинок** — данные диаграмм, карт, схем описываются таблицами и словами.
Проверка: `python scripts/validate_content.py content/<subject>/<id>.json` — должно быть `[OK]`, без `ERROR`.

Язык: ЕНТ-контент — русский. IELTS — учебный материал на английском, объяснения и советы на русском.

## 1. Общая структура файла

```json
{
  "id": "math-derivative",
  "subject": "math",
  "title": "Производная",
  "summary": "Одно предложение: что проверяет ЕНТ по этой теме.",
  "theory": ["markdown-блок 1", "markdown-блок 2"],
  "cards": [{ "front": "Производная $x^n$", "back": "$n x^{n-1}$" }],
  "contexts": [{ "id": "c1", "title": "Резервуар", "text": "markdown" }],
  "questions": [ ... ],
  "passage": "только IELTS reading: текст 650–900 слов",
  "transcript": "только IELTS listening: 450–750 слов",
  "words": [ ... только kind=vocab ... ],
  "prompts": [ ... только kind=writing | speaking ... ]
}
```

`id` и `subject` обязаны совпадать с манифестом. Индексы ответов — **с нуля**. Никаких комментариев и висячих запятых в JSON.

## 2. Markdown, который понимает сайт

Поддерживается: заголовки `##`/`###`, абзацы, списки `-` и `1.` (одна вложенность), таблицы `| a | b |`, цитаты `>`, `**жирный**`, `*курсив*`, `` `код` ``, блоки кода ```` ```python ````, формулы `$...$` и `$$...$$` (KaTeX), ссылки, callout-блоки:

```
:::tip Совет
Текст совета
:::
:::warn Ловушка
:::
:::example Пример
:::
:::formula Формула
:::
```

Не поддерживается: HTML, изображения, вложенность списков > 1. В JSON обратные слэши LaTeX удваиваются: `"$\\frac{a}{b}$"`, `"$\\sqrt{2}$"`.
Каждая строка с формулой должна содержать чётное число `$`. В вариантах ответов формулы тоже допустимы: `"$\\dfrac{1}{2}$"`. Многострочный код в варианте ответа — через ```` ``` ````.

## 3. Теория (`theory`)

Массив из 4–8 markdown-блоков, всего 400–900 слов. Структура блока: `## Заголовок`, короткое объяснение, `:::formula` с ключевыми формулами, `:::example` с полностью решённым примером в стиле ЕНТ, `:::warn` с типичной ловушкой. Пиши для 10-классника, который читает вечером после второй смены: коротко, конкретно, с числами. Последний блок — «Что спрашивают на ЕНТ» (3–5 пунктов).

`cards` — 6–12 карточек «вопрос → ответ» (формулы, даты, термины, определения). Для истории — даты и персоналии.

## 4. Вопросы (`questions`)

Общие поля:

| Поле | Обязательно | Описание |
|---|---|---|
| `id` | да | `q01`, `q02`… уникальный в файле |
| `type` | да | `single` · `multi` · `match` · `text` (text — только IELTS) |
| `difficulty` | да | 1 (базовый, ≈50 %), 2 (средний, ≈30 %), 3 (высокий, ≈20 %) |
| `text` | да | условие, markdown |
| `options` | да, кроме text | варианты, markdown |
| `answer` | да | список индексов (или строк для text) |
| `explanation` | да | решение/обоснование 1–5 предложений, с вычислениями |
| `why` | нет | `{"1": "почему неверен вариант с индексом 1"}` — для 1–2 сильных дистракторов |
| `context` | нет | id контекста из `contexts` |
| `tags` | нет | подтемы |
| `noShuffle` | нет | `true`, если порядок вариантов важен («все ответы верны», «TRUE/FALSE/NOT GIVEN», числа по возрастанию) |

### 4.1 `single` — один ответ из четырёх (ЕНТ)
Ровно 4 варианта (A–D), ровно один верный. Дистракторы — типичные ошибки (знак, потерянный множитель, неверная формула). Для IELTS допустимо 2–8 вариантов (TFNG = 3, matching headings = 5–8, MCQ = 4).

### 4.2 `multi` — один или несколько ответов из шести (ЕНТ, профильные)
Ровно 6 вариантов (A–F), верных 1–3. Баллы: без ошибок — 2, одна ошибка (лишний или пропущенный) — 1, две и более — 0. Хорошие multi: «выберите все верные утверждения/промежутки/уравнения с таким-то свойством».

### 4.3 `match` — установление соответствия (ЕНТ, профильные)
Две строки `rows` (A и B) и 4 общих варианта `options`; `answer` — `[индекс для A, индекс для B]`, индексы различны. Обе строки верно — 2 балла, одна — 1.
```json
{ "id": "q20", "type": "match", "difficulty": 2,
  "text": "Функция задана формулой $y=(x-2)^2-1$. Установите соответствие.",
  "rows": ["Нули функции", "Координаты вершины параболы"],
  "options": ["$(-2;-1)$", "$\\{1;3\\}$", "$(2;-1)$", "$\\{1;2\\}$"],
  "answer": [1, 2],
  "explanation": "$(x-2)^2=1 \\Rightarrow x=1$ или $x=3$; вершина $(2;-1)$." }
```

### 4.4 Контекстные задания
`contexts[]` — сценарий (задача с данными, документ, описание карты, текст для чтения), `questions[].context = "c1"`. К одному контексту — 5 вопросов (`single`, 4 варианта). Все 5 вопросов должны решаться только по контексту + знаниям темы.

### 4.5 `text` — ввод ответа (только IELTS)
```json
{ "id": "q07", "type": "text", "difficulty": 2, "text": "The survey involved ______ participants.", "answer": ["200"], "accept": ["two hundred", "200 participants"], "maxWords": 2, "explanation": "Абзац C: «…a sample of 200 people…»." }
```
Сравнение без учёта регистра, артиклей и лишних пробелов.

## 5. Нормы по предметам

| Предмет / вид | Теория | Вопросы |

| История (`lesson`) | 500–800 слов: даты, персоналии, термины, причины/итоги; `cards` 10–12 (даты) | ≥ 12 `single` без контекста + 1 контекст (документ/описание карты, 120–200 слов) × 5 `single` |

Сайт озвучивает транскрипт синтезом речи |

| IELTS writing (`writing`) | 500–900 слов: структура, лексика, критерии Band 6/7/8 | `prompts` 2–3: `{ "id": "w1-01", "task": 1, "title": "…", "prompt": "markdown (для Task 1 данные в таблице)", "minWords": 150, "minutes": 20, "samples": [{ "band": 6, "text": "…", "notes": ["по-русски, что мешает Band 7"] }, { "band": 7.5, "text": "…", "notes": [] }], "checklist": ["Есть overview", "…"] }` |

## 5.1 Казахская версия темы

Перевод кладётся в `content/kk/<предмет>/<id>.json`. Требования:

- `id`, `subject`, `kind` — как в русском файле; имя файла совпадает с `id`.
- Полное совпадение структуры: те же `id` вопросов, те же `type`, `difficulty`, `answer` (индексы!), то же количество и **порядок** `options` и `rows`, те же `context` и ключи `why`.
- Переводится только человекочитаемый текст. LaTeX, код, числа, IP-адреса не трогаем.
- Маркеры `:::tip` / `:::warn` / `:::example` / `:::formula` остаются, их заголовки переводятся.
- Терминология — как в казахских вариантах ЕНТ и школьных учебниках (санау жүйесі, туынды, пайыз, сақтар, ғұндар и т. д.).
- Проверка: `python scripts/validate_content.py content/kk/<предмет>/<id>.json`.

Тема без перевода не ломает пробник: сайт возьмёт русский файл и покажет предупреждение «часть тем ещё не переведена».

## 6. Качество

1. **Единственно верный ответ.** Реши каждую задачу сам, проверь арифметику дважды, убедись, что ни один дистрактор не может быть верным при другом прочтении.
2. **Объяснение — это решение**, а не «правильный ответ C».
3. **Без повторов**: разные числа, разные формулировки, разные подтемы внутри темы.
4. **Стиль ЕНТ**: короткие формулировки, «Найдите…», «Укажите…», «Установите соответствие…», «Выберите все верные утверждения…».
5. **Сложность**: примерно 50 % / 30 % / 20 %.
6. **Даты и факты по истории** — только по официальной спецификации и списку 100 дат НЦТ (см. `docs/research/ubt-mandatory-spec.md`).
7. **Программирование** — Python 3; код в ```` ```python ````; вопросы «что выведет программа» с трассировкой в объяснении.
8. Никаких ссылок на картинки, «см. рисунок», «на графике выше».

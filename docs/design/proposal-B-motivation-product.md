# Proposal B — «ВЕКТОР»: мотивация и продукт

> Веб-приложение для подготовки к ЕНТ («Математика – Информатика») и IELTS Academic.
> Линза этого документа: **что заставит уставшего десятиклассника после второй смены открывать сайт каждый вечер и не бросить за 2 года, и что заставит его рекомендовать сайт одноклассникам**. Всё это — без ущерба для педагогики.
>
> Рабочее название: **ВЕКТОР** (у вектора есть направление и длина — «куда» и «сколько осталось»). Слоган: `140 / 9.0` — максимум ЕНТ и максимум IELTS.

---

## 1. Видение и «крючок рекомендации»

**Видение в трёх предложениях.**
1. ВЕКТОР — это персональный тренер, который каждый вечер даёт одну 20-минутную миссию и показывает, как сегодняшние 20 минут двигают предсказанный балл ЕНТ и band IELTS.
2. Всё обучение происходит внутри сайта: короткая теория → задачи в формате экзамена → разбор ошибок → интервальное повторение → пробники с таймером; ученику не нужен репетитор, чтобы понять, *что* делать завтра.
3. Продукт устроен так, что прогресс виден каждый день, а не только «в конце»: число, которое растёт, — это главная причина возвращаться.

**Почему он порекомендует сайт одноклассникам (hook).**
Не «здесь много задач» (это есть везде), а **«смотри, мой прогноз ЕНТ был 71, за месяц стал 84 — вот карточка»**. Три конкретных механизма:
- **Прогноз-число.** Прогноз ЕНТ из 140 и band IELTS — на главной, обновляется после каждой сессии. Его хочется показать. «Прогноз» звучит серьёзнее любых звёздочек.
- **Карточка недели (share card).** В воскресенье сайт рисует картинку (canvas → PNG): «Неделя 12. +3 балла к прогнозу. 6/7 дней. Лучшая тема: логарифмы». Одна кнопка «Поделиться» → скачать/отправить в Telegram/WhatsApp. Одноклассник видит картинку — спрашивает «что это».
- **Дуэль по ссылке (v1.5).** Ученик кидает ссылку на «дуэль по теме „Проценты“: 10 задач за 6 минут». Друг открывает, решает без регистрации, видит сравнение. Ссылка = вирусная петля без бэкенда (результат кодируется в URL).

Формулировка для продвижения: **«Сайт, который говорит твой балл ЕНТ прямо сейчас — и что делать сегодня вечером, чтобы он вырос».**

## 3. Учебная петля

### 3.1 Вечерняя сессия по минутам (стандартная миссия, ~20 мин)

Контекст: вторая смена, ученик дома ~19:30–20:00, устал. Миссия должна начинаться **без выбора** — выбор уже сделан алгоритмом.

| Мин | Шаг | Что происходит | Зачем |
|---|---|---|---|
| 0–1 | Старт | Экран «Сегодня»: одна кнопка «Начать миссию (≈20 мин)». Показано 3 шага. | Ноль решений на входе. |
| 1–6 | **Повторение** (SRS) | 8–12 быстрых вопросов из очереди повторения (ЕНТ-темы + IELTS-слова вперемешку по 2–3 предметам). Мгновенная проверка. | Разогрев, лёгкие победы, борьба с забыванием. |
| 6–14 | **Новое / Прокачка** | Либо теория новой темы (2–4 блока + чекпоинты), либо практика слабой темы (6–8 задач). Один предмет. | Основной прирост мастерства. |
| 14–19 | **Формат экзамена** | 4–5 задач в стиле ЕНТ (или один IELTS-микро-тест: 1 Listening Part / 5 Reading вопросов / 1 Speaking Part 1 с таймером) — под таймером на задачу. | Привыкание к формату и темпу. |
| 19–20 | Итог | Экран: «+34 XP · точность 78% · прогноз ЕНТ 84 → 85 · серия 12 дней». Кнопка «Ещё 10 минут?» (опционально, второй блок). | Закрыть цикл вознаграждением, показать движение числа. |

Варианты миссии, которые генерирует план: `standard` (20 мин), `light` (10 мин — только повторение; для дней с контрольными), `deep` (45 мин — выходные: полная тема + мини-пробник), `mock` (240 мин — пробник, раз в 3–4 недели, суббота).

### 3.2 Теория → практика → ошибки → повторение

1. **Теория** подаётся блоками по 2–4 абзаца. После каждого 2–3-го блока — **чекпоинт** (1 вопрос). Ответил верно — блок помечен «прочитан»; неверно — раскрывается подсказка, вопрос вернётся в конце. Теория без чекпоинтов не засчитывается в coverage.
2. **Практика** — сессия из 8–12 задач с немедленным разбором. Разбор обязателен: объяснение + «почему другие варианты неверны» (для ЕНТ это критично — дистракторы там намеренные).
3. **Ошибка** создаёт объект `mistake` с полем `reason` (ученик выбирает одним тапом: «не знал теорию» / «невнимательность» / «не хватило времени» / «арифметика»). Причина влияет на то, что показывать при повторении: «не знал теорию» → сначала ссылка на блок теории, потом задача.
4. **Повторение** — SRS по вопросам и по «карточкам темы» (ключевые факты/формулы, автособранные из блоков `type: "card"`). Алгоритм — упрощённый SM-2:
   - интервалы `[1, 3, 7, 16, 35, 70, 140]` дней;
   - верно → следующий интервал; неверно → интервал сбрасывается на 1 день и `lapses += 1`;
   - «легко» (ответ < 10 сек и верно) → пропуск одного шага.
   Каждая тема имеет `retention` — доля её карточек, которые не просрочены.

### 3.3 Мастерство темы (0–100)

Для темы `t`:

```
acc_t      = EMA точности по задачам темы, α = 0.3, последние ответы весят больше
             (мультивыбор: частичный балл 0 / 0.5 / 1 как «точность»)
cov_t      = (прочитанных блоков с пройденным чекпоинтом / всего блоков) * 0.5
           + (решённых уникальных задач / min(20, всего задач в теме)) * 0.5
ret_t      = карточек не просрочено / всего карточек в SRS по теме (если карточек 0 → ret_t = cov_t)
decay_t    = exp(-days_since_last_activity / 45)         # период полураспада ≈ 31 день

mastery_t  = 100 * (0.5*acc_t + 0.3*cov_t + 0.2*ret_t) * (0.6 + 0.4*decay_t)
```

Статусы: `<25` не начато/слабо, `25–59` изучаю, `60–84` уверенно, `≥85` освоено. Тема «требует повторения», если `decay_t < 0.5` и `mastery_t` раньше была ≥60.

### 3.4 Прогноз балла ЕНТ (из 140)

Веса тем — это **сколько баллов экзамена приходится на тему** (из `subjects/*.json`, поле `examWeight`, сумма по предмету = максимум предмета: История 20, МатГрам 10, Чтение 10, Математика 50, Информатика 50).

Шаг 1 — модельный прогноз по мастерству (калибровка: мастерство 100 ≠ гарантия, а мастерство 0 ≠ ноль, потому что угадывание из 5 вариантов даёт 20%):

```
p_t          = 0.20 + 0.75 * (mastery_t / 100)          # вероятность верно решить задание темы
model_subj   = Σ_t examWeight_t * p_t                    # по темам предмета
model_total  = Σ_subj model_subj
```

Шаг 2 — смешивание с реальными пробниками (пробники честнее модели, но шумные):

```
mock_avg     = взвешенное среднее последних 3 полных пробников (веса 0.5, 0.3, 0.2, новейший первый)
n            = число полных пробников за последние 90 дней
w_mock       = min(0.6, 0.2 * n)                          # 0 пробников → 0; 3+ → 0.6
predicted    = (1 - w_mock) * model_total + w_mock * mock_avg
```

Мини-пробники и односубъектные пробники входят в `mock_avg` с масштабированием на полный балл предмета и весом ×0.5.

Шаг 3 — отображение: целое число `/140` + доверительный диапазон `±(8 − 2n)`, но не меньше ±3. На дашборде: «**84** ± 6 / 140 · цель 110». Пороговые метки на шкале: `50` (грант — минимум), `70`, `100`, `120`.

### 3.5 Прогноз IELTS band

```
L_band, R_band  = таблица raw→band (Academic) по последним 3 тестам, EMA α=0.4
W_band          = среднее self-check по 4 критериям (TA/TR, CC, LR, GRA) − 0.5   # штраф за самооценку
S_band          = среднее self-check по 4 критериям (FC, LR, GRA, P) − 0.5
overall         = округление (L+R+W+S)/4 к ближайшим 0.5 по правилам IELTS
                  (x.25 → x.5, x.75 → (x+1).0)
```

Пока по навыку нет ни одного теста — показывается «—» и подсказка «Пройди диагностический тест (20 мин)». Writing/Speaking помечены иконкой «самооценка» — честно.

## 4. Модуль пробников (ЕНТ)

### 4.1 Формат (верный ЕНТ)

| Блок | Заданий | Баллы | Формат ответов |
|---|---|---|---|
| История Казахстана | 20 | 20 | один ответ из 5 |
| Математическая грамотность | 10 | 10 | один ответ из 5 |
| Грамотность чтения | 10 | 10 | контекст (текст) + один ответ из 5 |
| Математика (профиль) | 40 | 50 | 30 × один ответ (1 б) + 10 × несколько ответов (0–2 б) |
| Информатика (профиль) | 40 | 50 | 30 × один ответ (1 б) + 10 × несколько ответов (0–2 б) |
| **Итого** | **120** | **140** | **240 минут** |

Важно проверять актуальный формат перед сезоном (структура ЕНТ менялась в 2021 и 2023); в `content/exam-format.json` все числа вынесены, чтобы менять без кода.

**Скоринг мультивыбора** (как в ЕНТ): выбрано ровно все верные → 2; одна ошибка (один лишний или один пропущенный) → 1; иначе → 0. Формула в коде:

```
errors = |chosen \ correct| + |correct \ chosen|
score  = errors == 0 ? 2 : errors == 1 ? 1 : 0
```

### 4.2 UX прохождения
- **Старт**: выбор режима, предупреждение о времени, «пробник считается только при завершении».
- **Таймер** общий на 240 мин (можно завершить раньше). Красный за 15 минут до конца.
- **Навигатор**: сетка 1–120 (по предметам разбита на вкладки), цвета: серый — не отвечено, синий — отвечено, жёлтый — «помечено», текущее — обведено. Флажок «вернуться позже».
- **Автосохранение** каждого ответа в `localStorage` (`attempts.active`) — обновил страницу/сел телефон → продолжил. Таймер считается от абсолютного `startedAt`, а не от «тиков», поэтому обман через закрытие вкладки невозможен.
- **Без мгновенного разбора** во время пробника — разбор только на странице результата (иначе это тренировка, а не пробник).
- **Телефон**: задание на весь экран, варианты — крупные кнопки, навигатор — в шторке снизу.

### 4.3 Мини-режим
- **Мини-ЕНТ**: 45 минут, 30 заданий, пропорционально: История 5, МатГрам 3, Чтение 2 (один текст), Математика 10 (7+3), Информатика 10 (7+3). Максимум 36 баллов → масштабируется к 140 для прогноза.
- **Предмет-пробник**: полный блок одного предмета с его временем (Математика: 40 заданий, 80 мин).
- **Блиц темы**: 10 заданий, 6–8 минут, без разбора до конца — используется для дуэлей.

### 4.4 Результат
Балл, разбивка по предметам, **разбивка потерь по темам** («−6: Производная, −4: Логарифмы»), время на задание (гистограмма), сравнение с целью и прошлыми попытками. Все ошибочные задания автоматически попадают в SRS с интервалом 1 день. Кнопка «Разобрать ошибки сейчас (≈15 мин)» → сессия `mistakes`.

## 5. Модуль IELTS (Academic)

Ограничение: статический сайт, без сервера. Аудио — ссылки/встраивание (YouTube с таймкодами, mp3 по прямой ссылке), запись голоса — только локально через `MediaRecorder` с возможностью скачать.

### 5.1 Listening
- **Контент**: `content/ielts/listening/*.json` — секция = `{audioUrl, transcript, questions[], answerKey}`. Аудио по ссылке (`<audio src>` или YouTube iframe с `start`).
- **Практика**: бланк ответов как на экзамене (ввод текста; проверка нечувствительна к регистру, допускает числа словами/цифрами по `accept[]`). После проверки — транскрипт с подсветкой мест ответов.
- **Тренировки навыка**: «Диктант чисел/имён» (Part 1), «Слушай и следуй за транскриптом» (подсветка бегущей строки по таймкодам), «Предсказание ответа» (прочитай вопросы за 30 сек — угадай тип слова).
- **Русские пояснения**: ловушки (перефраз, отвлекающие ответы, «but actually…»).

### 5.2 Reading
- **Контент**: passage (600–900 слов) + 13–14 вопросов всех типов: T/F/NG, Y/N/NG, matching headings, matching information, sentence completion, summary completion, MCQ.
- **UX**: две колонки на десктопе, на телефоне — переключение «Текст / Вопросы» с плавающей кнопкой. Таймер 20 мин, счётчик слов в минуту.
- **Тренировки**: skimming (30 сек на абзац → выбери заголовок), scanning (найди число/имя за 10 сек), разбор «NG vs False» с русскими объяснениями.
- **Разбор**: для каждого вопроса — подсвеченное место в тексте и перефраз «в вопросе → в тексте».

### 5.3 Writing
- **Task 1** (график/таблица/процесс/карта — SVG/PNG в контенте) и **Task 2** (эссе). Таймер 20/40 мин, редактор с счётчиком слов (мин. 150/250), автосохранение черновика.
- **Self-check рубрика** после отправки — чек-лист по 4 критериям, по 4–5 пунктов «да/нет» на критерий (например, TR: «есть чёткая позиция во введении?», «каждый абзац раскрывает одну идею?», «есть пример?»; CC: «используются связки, но не более 1 на предложение?»; LR: «≥5 слов из академического списка?»; GRA: «≥3 сложных предложения?», «проверил артикли?»). Каждый критерий → band-оценка 5.0–7.5 по доле «да». Итог = среднее − 0.5.
- **Обучающие материалы**: структуры (4-абзацное эссе), 12 типов заданий Task 2 с планами, банк «band 7 фраз» (не шаблонов-клише — их экзаменаторы штрафуют, об этом отдельно написано), «эссе band 5.5 — найди 10 ошибок» (интерактивно: клик по ошибке).
- **Лайтовая автопроверка в браузере** (без ИИ): длина, повторяемость слов (TTR), доля связок, средняя длина предложения, наличие всех абзацев, запрещённые клише («In a nutshell», «This essay will discuss»). Показывается как «сигналы», не как балл.

### 5.4 Speaking
- **Cue cards** Part 1 (топики), Part 2 (карточка + 1 мин подготовки + 2 мин ответа, таймер с фазами), Part 3 (вопросы-обсуждение).
- **Запись**: `MediaRecorder` → воспроизвести, скачать `.webm`. Не хранится в localStorage (размер), только «сделал 1 запись сегодня».
- **Self-check** по 4 критериям (Fluency, Lexical, Grammar, Pronunciation) — простые «да/нет» с подсказками («были паузы > 3 сек?», «использовал ≥2 idiom/collocation?»).
- **Тренировки**: «Ответь за 30 сек» (Part 1 фразы-открывашки), «Расширь ответ» (дано короткое → добавь причину + пример), «Shadowing» (аудио носителя + текст).

### 5.5 Словарь (SRS)
- Списки: Academic Word List (570 семейств, разбиты на 10 подсписков), 20 тематических списков Speaking/Writing (education, environment, technology…), «мои слова» (ввод вручную).
- Карточка: слово · IPA · часть речи · перевод · определение на английском · пример · коллокации · «в Writing подходит для…». Обратная сторона проверяется через «вспомнил / не вспомнил / легко» + раз в 3 повторения — ввод слова по переводу.
- Тот же SM-2, что и для ЕНТ. Дневная норма по умолчанию: 15 новых + все просроченные (кап 60).

### 5.6 Порядок обучения (по умолчанию, план IELTS)
Фаза 1 (месяцы 1–3): словарь + Reading + Listening (измеримы, дают быстрый рост band). Фаза 2 (месяцы 4–8): Writing Task 2 по типам, Speaking Part 1–2. Фаза 3 (последние 3 месяца перед датой): полные тесты по расписанию, Task 1, Part 3.

## 6. Учебный план: алгоритм

### 6.1 Входные данные (из onboarding / settings)
```
examDates      = { ent: "2028-06-10", ielts: "2027-11-15" }   # ent — оценочная, обновляется
hoursPerWeek   = 7                                             # ползунок 3–20
schedule       = { shift: 2,
                   weekdays: { start: "20:00", end: "22:30" }, # окно после школы
                   weekend:  { start: "11:00", end: "18:00" },
                   busyDays: ["2026-10-14"] }                  # контрольные, олимпиады
goals          = { ent: 110, ielts: 6.5 }
priority       = 0.7                                          # доля времени на ЕНТ (авто: по близости дат и разрыву цели)
```

### 6.2 Шаг 1 — распределение бюджета между ЕНТ и IELTS

```
gapENT   = max(0, goal_ent - predicted_ent) / 140
gapIELTS = max(0, goal_ielts - predicted_ielts) / 3
urgX     = 1 / max(30, daysTo(examX))                         # чем ближе, тем важнее
shareENT = (gapENT*urgENT) / (gapENT*urgENT + gapIELTS*urgIELTS)   # clamp 0.3..0.85
```
Пользователь может зафиксировать `priority` вручную — тогда авто не применяется.

### 6.3 Шаг 2 — приоритет тем (внутри ЕНТ)

Для каждой темы `t` предмета `s`:
```
need_t    = examWeight_t * (1 - mastery_t/100)                # сколько баллов «лежит» в теме
due_t     = 1 + 0.5 * (просроченных карточек / всего)          # долг по повторению
prereq_t  = все prerequisites темы имеют mastery ≥ 40 ? 1 : 0.2 # не прыгать вперёд
recency_t = daysSince(lastActivity_t) > 21 && mastery_t ≥ 60 ? 1.4 : 1
priority_t = need_t * due_t * prereq_t * recency_t
```
Аналогично для IELTS: «темы» = навыки × подтипы заданий, `examWeight` = 1 для всех, `mastery` = band-прогноз навыка, нормированный.

### 6.4 Шаг 3 — раскладка недели

```
minutes = hoursPerWeek * 60
slots   = по расписанию: будни → 1 слот 20–30 мин (или 2, если минут хватает), сб/вс → слот 45–90 мин
loop по слотам недели:
   тип слота = 'deep' если ≥45 мин, 'standard' если 20–30, 'light' если <20 или busyDay
   предмет   = ЕНТ или IELTS по shareENT (чередование с балансом накопленной ошибки, как dithering)
   тема      = argmax priority_t среди тем этого предмета, не выбранная в последние 2 дня
   миссия    = { review: SRS-очередь (кап 12), main: тема + режим (theory если cov_t < 0.5 иначе practice), exam: 5 задач формата }
пробник:     раз в 4 недели (последние 3 месяца — раз в 2 недели) в субботу, слот 'mock', заменяет deep
```
Обучающие ограничения: не более 2 новых тем в неделю на предмет (иначе поверхностность); каждая новая тема получает практику в следующие 2 дня (иначе распад); пятница по умолчанию — `light` (усталость недели).

### 6.5 Шаг 4 — ежедневная миссия и адаптация
- Миссия на сегодня строится **утром** (при первом открытии) из плана + свежей SRS-очереди. Если вчера пропущено — сегодняшняя миссия **не удваивается** (иначе прокрастинация): просроченные карточки распределяются на 3 дня.
- Если ученик сделал больше (нажал «Ещё 10 минут») — дополнительные минуты списываются с самого «дорогого» дня недели.
- Пересчёт плана: каждое воскресенье автоматически + при изменении настроек + после пробника.
- Ученику показывается **«Почему сегодня это?»**: «Производная: вес 4 балла, мастерство 31, последний раз — 9 дней назад».

### 6.6 Горизонт 2 лет — «сезоны»
Чтобы 20 месяцев не сливались, план делится на **сезоны по 8 недель** с названием и целью («Сезон 3: Алгебра до 70», «Сезон 7: IELTS Reading 6.5»). В конце сезона — «сезонный отчёт» и обновление целей. Это также ритм для share-карточек.

## 7. Система мотивации (конкретно, не по-детски)

Принцип: **награда за поведение, а не за результат** (серия — за занятие, а не за 100%), **число, которое растёт** (прогноз), **не наказывать за жизнь** (заморозки), **никаких мультяшных персонажей** — тон «тренер», не «мама».

### 7.1 Серия (streak)
- День засчитан, если выполнена миссия (любого типа, минимум `light` = 10 мин) **или** решено ≥10 задач/карточек.
- **Заморозка**: 1 заморозка накапливается за каждые 7 подряд дней (макс. 3 в запасе). Тратится автоматически при пропуске. Показывается прозрачно: «Серия 23 · заморозок 2».
- Ночная граница — **03:00**, а не 00:00 (реалистично для второй смены).
- Восстановление: после потери серии — «Серия 0, рекорд 41» (рекорд остаётся, лучше чем стыд).

### 7.2 XP и уровни
```
XP за: верный ответ +2 (практика), +3 (SRS-повтор вовремя), +1 (неверный, но с разбором и указанием причины),
       чекпоинт теории +5, миссия целиком +25, deep-сессия +50, полный пробник +150,
       эссе с self-check +40, speaking-запись +20
Множитель серии: ×1.1 при серии ≥7, ×1.2 при ≥30 (кап). Не больше — иначе гринд.
Уровень: XP_к_уровню(n) = 200 * n^1.5   (ур.2 = 566, ур.5 = 2236, ур.10 = 6325, ур.20 = 17889)
```
Названия уровней — математические/технические, 20 штук: «Аксиома → Лемма → Теорема → … → Инвариант → Изоморфизм → Комплексность → Сингулярность». Уровень показан цифрой и названием, без эмодзи в UI-хедере.

### 7.3 Бейджи (≈30, три группы)
- **Дисциплина**: «7 дней», «30 дней», «100 дней», «Сова» (10 сессий после 22:30), «Ранний» (сессия до 9:00 в выходной), «Без заморозок 30 дней».
- **Мастерство**: «Первая тема на 85+», «Раздел освоен» (все темы раздела ≥60), «Чистый пробник» (предмет без ошибок), «+10 к прогнозу за месяц», «Band up» (рост band на 0.5).
- **Работа над ошибками**: «100 ошибок разобрано», «Реванш» (ошибка → 3 верных повтора подряд), «Честность» (100 причин ошибок указано).
Бейдж выдаётся тихо: тост + запись в ленте; никаких модалок с конфетти дольше 1.5 сек.

### 7.4 Итог недели (воскресенье)
Экран «Неделя 12»: минуты, дни, точность, лучшая/худшая тема, изменение прогноза, следующий сезонный рубеж. **Share-карточка** 1080×1350 (Instagram-story-совместимый формат) рисуется на `<canvas>`, скачивается как PNG — «Поделиться в Telegram». Ученик выбирает, показывать ли балл (приватность).

### 7.5 Маленькие вещи, которые работают
- На «Сегодня» — **одно** число-крючок: «Прогноз: 84 (+1 за неделю)». Не десять виджетов.
- **Ощущение конца**: после миссии экран «Готово на сегодня» — сайт сам говорит «хватит», это снимает вину и повышает возврат завтра.
- «**Ещё 10 минут?**» — опция, не давление.
- Пропустил 3+ дня — при возврате **не** «ты потерял серию», а «С возвращением. Лёгкая миссия на 10 минут, чтобы вернуться в ритм».
- Сравнение только с собой (в v1). Лиги/дуэли — когда появятся друзья на платформе (раздел 10).

  - Тёмная: фон `#0B0F17`, поверхность `#121826`, поверхность-2 `#1A2234`, текст `#E6EAF2`, вторичный `#8B94A7`, границы `#232C3F`.
  - Светлая: фон `#F7F8FA`, поверхность `#FFFFFF`, текст `#0F1522`, вторичный `#5B6478`, границы `#E3E7EE`.
  - **Акцент ЕНТ** — электрик-циан `#22D3EE`; **акцент IELTS** — янтарь `#F5B544`; успех `#34D399`; ошибка `#F87171`; предупреждение `#FBBF24`. Два акцента — чтобы контекст (ЕНТ vs IELTS) читался мгновенно, без надписей.
- **Типографика**: `Manrope` (UI, поддерживает кириллицу, геометричная, «техно») + `JetBrains Mono` (код, числа-счётчики, таймер) + KaTeX для формул. Размеры: 15px базовый на десктопе, 16px на телефоне; заголовки 28/22/18; числа-прогнозы — 48px моно с `font-variant-numeric: tabular-nums`.
- **Сетка**: max-width 1100px, сайдбар 240px на ≥1024px; на телефоне — одна колонка, нижняя таб-панель 56px + safe-area. Все интерактивные цели ≥44px. Практика на телефоне: варианты — карточки во всю ширину, кнопка «Ответить» — фиксирована внизу.
- **Формулы**: KaTeX с `throwOnError:false`, `\displaystyle` для выделенных; в тёмной теме цвет формул наследуется.
- **Движение**: 150–200 мс, `cubic-bezier(.2,.8,.2,1)`; `prefers-reduced-motion` уважается.

**5 деталей «премиум-ощущения»:**
1. **Число прогноза анимируется**: после сессии `84 → 85` крутится как одометр (моно-шрифт, 600 мс), а под ним тонкая зелёная стрелка `+1`. Это главный «дофаминовый» момент — он должен быть красивым.
2. **Кольца мастерства** на карточках тем (SVG, 3px, цвет от серого к акценту через `color-mix`), а у освоенных — тонкая заливка. Список тем читается как «карта» без единой цифры.
3. **Разбор ответа не «прыгает»**: варианты не перерисовываются, а в выбранном и правильном плавно появляются левые полоски цвета; объяснение раскрывается снизу с `height` transition. Ощущение спокойствия, а не «ошибка!».
4. **Таймер пробника** в моно-шрифте с тонкой прогресс-полоской по верхнему краю экрана (1px, меняет цвет на янтарный за 30 мин и красный за 10). Никаких мигающих часов.
5. **Скелетоны и офлайн**: контент кэшируется в `Cache Storage` через простой service worker (после первого посещения сайт работает без интернета — важно для телефона в автобусе); при загрузке — скелетоны, не спиннеры. Share-карточка недели рендерится в фирменной сетке с тем же шрифтом — она должна выглядеть как то, что не стыдно выложить.

Доступность: контраст ≥4.5:1 на тексте, фокус-кольца, клавиатура в практике (`1–5` — выбрать вариант, `Enter` — ответить/далее, `F` — пометить в пробнике).

## 10. Путь роста (когда начнёт продвигать)

Порядок — по соотношению «вирусность / стоимость» для одного разработчика без бэкенда-опыта.

1. **v1.1 — Дуэли по ссылке и share-карточки (0 бэкенда).** Результат блица кодируется в URL (`#/duel/<base64url{topic,seed,score,time,name}>`), задания генерируются детерминированно по `seed`. Друг решает тот же набор и видит «ты vs Нурбол». Это первый канал распространения.
2. **v1.2 — Аккаунты и синхронизация (Supabase).** Email/Google-вход, таблица `progress(user_id, json, updated_at)` — тот же JSON, что в localStorage, с «последний записавший побеждает» + локальный бэкап. Ничего в архитектуре менять не надо: `store.js` получает второй адаптер.
3. **v1.3 — Лиги и лидерборды.** Еженедельные лиги по XP по 20–30 человек (как в Duolingo, но с фильтром «моя школа/класс» — код класса). Публичный только XP и серия, **никогда** — прогноз балла (стыд убивает возвращаемость слабых).
4. **v1.4 — Режим учителя/наставника.** Учитель создаёт «класс» (код), видит heat-map тем по классу, назначает миссии («к пятнице — логарифмы»), выгружает CSV. Это канал в школы: один учитель = 25–100 учеников.
5. **v1.5 — Казахский язык интерфейса и контента (ҰБТ на казахском).** Контент-схема уже с полем `lang`; тексты UI — в `i18n/ru.json`, `kk.json`. Половина сдающих ЕНТ учится на казахском — это удвоение аудитории.
6. **v1.6 — Больше направлений ЕНТ.** Схема предметов позволяет добавить «Физика – Математика», «Химия – Биология»: новый `subjects/index.json` + папки тем. Профиль пользователя получает `track`.
7. **v2 — ИИ-проверка Writing/Speaking (Claude API через серверную функцию),** авто-генерация вариаций задач по шаблонам, рекомендательные объяснения «почему я ошибся». Только после того, как есть аккаунты (ключи API нельзя класть в статический сайт).
8. **Монетизация (если понадобится)**: бесплатно — всё обучение; платно — расширенные пробники с «официальными» вариантами прошлых лет, режим учителя, семейный отчёт родителям. Никогда не запирать SRS и миссии за пейволом — это ядро привычки.

Метрики, за которыми следить с первого дня (считаются локально, показываются в `#/stats` → «для разработчика»): D1/D7/D30-возврат, медианная длительность сессии, доля дней с миссией, «прогноз через 30 дней − прогноз в день 0», кол-во скачанных share-карточек, кол-во открытых дуэлей.

## Приложение: приоритет реализации v1 (порядок разработки)

1. `store.js` + схема + экспорт/импорт · роутер · оболочка (сайдбар/таб-панель, темы).
2. Контент-загрузчик + рендер темы (markdown → HTML, KaTeX) + чекпоинты.
3. Практика (single/multi/input) с разбором, причинами ошибок, XP.
4. SRS-движок + очередь «Повторить сейчас».
5. Мастерство и прогноз ЕНТ · дашборд «Сегодня» с миссией (сначала простое правило, потом полный планировщик).
6. Пробник (полный/мини) с автосохранением и результатом по темам.
7. IELTS: словарь-SRS → Reading → Listening → Writing (рубрика) → Speaking (таймер).
8. План недели (алгоритм §6), сезоны, итог недели, share-карточка.
9. Бейджи, статистика, service worker/офлайн.

Контент для старта (минимум, чтобы петля работала): по 6–8 тем на предмет ЕНТ с 15–25 задачами каждая (≈600 задач), 1 полный пробник, AWL-списки 1–3, 3 Reading passage, 2 Listening секции, 6 промптов Writing, 20 cue cards.

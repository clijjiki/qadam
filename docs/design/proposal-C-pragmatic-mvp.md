# «Дайын» — дизайн-предложение C: прагматичный MVP

> *Дайын* (каз. «готов») — сайт, на котором 10-классник из Казахстана за 1,5–2 года дома готовится к ЕНТ (мат-инф) и IELTS Academic.
> Версия 1 — статический сайт на vanilla JS без сборки, контент в JSON, прогресс в localStorage.

**Принцип этого документа:** каждая страница, формула и поле в JSON либо даёт ценность в первый день, либо вычёркивается. Всё, что «потом» — в разделе 10.

## 0. TL;DR

| Что | Решение v1 |
|---|---|
| Ядро | Тема = теория (markdown + KaTeX) → практика (10 вопросов с мгновенным разбором) → исправление ошибок → повтор по интервалам |
| Измерение | Мастерство темы 0–100 (точность × покрытие × забывание) → прогноз ЕНТ /140 и IELTS band |
| Экзамен | Пробный ЕНТ по официальному чертежу (5 секций, 240 мин, частичный балл за мультиответ) + мини-режим на 15–50 мин |
| IELTS | Reading/Listening с авто-проверкой и таблицей band, словарь с SRS, Writing с рубрикой самопроверки, Speaking с таймером и cue cards |
| План | Дата экзамена + часы/неделю + шаблон «2-я смена» → недельный план → 2–4 миссии на день по 15–25 минут |
| Мотивация | Серия дней с одной «заморозкой» в неделю, XP/уровни, 14 бейджей за реальные достижения, воскресный отчёт |
| Хранение | Один объект `dayin.v1` в localStorage, экспорт/импорт JSON, `schemaVersion` для миграций |
| Стек | `index.html` + ES-модули + CSS-переменные, KaTeX и marked с CDN, `start.bat` → `python -m http.server` |

## 1. Видение и «крючок»

**Видение (3 предложения).**
«Дайын» — это личный тренер, который каждый вечер после второй смены говорит ученику ровно одно: *что делать в ближайшие 25 минут*, и после этого показывает, на сколько баллов он стал ближе к цели. Вся подготовка — теория, задачи, ошибки, пробники, словарь IELTS — живёт в одном месте и работает с телефона и ноутбука без интернета после первой загрузки. Через два года ученик приходит на ЕНТ и IELTS уже зная свой результат с точностью до ±5 баллов, потому что видел его на дашборде каждую неделю.

**Почему он порекомендует сайт друзьям (крючок).**
Единственная цифра на главной — **«Прогноз ЕНТ: 94 из 140 (+3 за неделю)»**. Она честная (считается по формуле, а не «на глаз»), она меняется от каждого занятия, и её хочется показать. Ни один бесплатный ресурс в Казахстане не показывает ученику *его собственный* прогнозный балл в реальном времени, а курсы за 30–60 тыс. тг в месяц ему недоступны из-за второй смены. Второй крючок — кнопка «Экспорт прогресса»: файл можно скинуть другу, и он видит, что сайт настоящий, а не очередной «сборник тестов».

## 2. Информационная архитектура

### 2.1 Маршруты (hash-роутинг)

Роутер — таблица `pattern → модуль страницы`. Каждый модуль экспортирует `render(root, params, query)` и опционально `unmount()`. Параметры темы/предмета — dotted-id из контента, без URL-encode проблем.

| Маршрут | Назначение | Основные блоки UI |
|---|---|---|
| `#/` | **Дашборд «Сегодня»** | (1) Карточка прогноза: ЕНТ /140 + IELTS band, дельта за 7 дней; (2) «Миссии на сегодня» — 2–4 карточки с минутами и кнопкой «Начать»; (3) Серия дней + XP-полоса уровня; (4) Мини-сетка мастерства по 5 предметам; (5) «Ближайший пробник: сб, 60 мин» |
| `#/onboarding` | Первый запуск (одноразово, 4 шага) | Имя → даты экзаменов и цели (балл, band) → часов в неделю + шаблон расписания (пресет «2-я смена») → готово, первая миссия |
| `#/ent` | Хаб ЕНТ | 5 карточек предметов: мастерство, прогноз баллов из макс., «слабые темы: 3», кнопка «Пробник» |
| `#/subject/:subjectId` | Предмет | Список тем в порядке программы: кольцо мастерства, вес в экзамене («~4 вопроса»), статус (не начата / изучаю / освоена / требует повтора), фильтр «только слабые» |
| `#/topic/:topicId` | **Урок: теория** | Заголовок + «≈ 12 мин»; markdown-блоки с KaTeX; блоки-примеры (сворачиваемые решения); блоки «Проверь себя» (1 вопрос inline); внизу: «Перейти к практике (10 вопросов)» и «Карточки темы (7)» |
| `#/practice/:topicId` | **Практика темы** | Режим фокуса: тонкий прогресс-бар, вопрос, варианты (клавиши 1–8), «Ответить» → мгновенный разбор («почему верно / почему другие нет»), «Далее». В конце — «Исправь ошибки» (повтор неверных) и карточка итога |
| `#/practice/:topicId?mode=hard` | Практика «сложные» | То же, вопросы difficulty ≥ 3 и мультиответ |
| `#/review` | **Повторение (SRS)** | Очередь карточек на сегодня: ошибки из практики, факты (даты/термины истории), слова IELTS. Кнопки «Не помню / Сложно / Помню» |
| `#/mock` | Пробники | «Полный ЕНТ (240 мин)», «Мини по предмету (10 вопр.)», «Экспресс-ЕНТ (30 вопр., 55 мин)»; история попыток с баллами |
| `#/mock/run/:attemptId` | **Прохождение пробника** | Таймер, панель навигации по секциям и номерам (отвечен/пропущен/помечен), вопрос, «Пометить», «Завершить секцию». Автосохранение каждого ответа |
| `#/mock/result/:attemptId` | Результат пробника | Балл /140, по секциям, сравнение с целью и предыдущим, разбор каждого вопроса, «Добавить ошибки в повторение» (авто) |
| `#/ielts` | Хаб IELTS | 4 карточки навыков с оценкой band, словарь (слов выучено / к повтору), «Следующий: Reading Passage 3» |
| `#/ielts/vocab` | Словарь | Наборы по темам (Education, Environment…), режимы: учить новые (10), повторять (SRS), проверка ru→en |
| `#/ielts/reading/:id` | Reading passage | Двухпанельный layout (текст слева, вопросы справа; на телефоне — вкладки), таймер 20 мин, типы TFNG/YNNG/MCQ/matching/gap, разбор с русскими объяснениями и подсветкой места в тексте |
| `#/ielts/listening/:id` | Listening section | Встроенное аудио (YouTube/mp3-ссылка), вопросы, транскрипт после проверки, разбор |
| `#/ielts/writing/:id` | Writing Task 1/2 | Задание, таймер 20/40 мин, редактор с счётчиком слов, после сдачи: рубрика самопроверки (4 критерия), образец на band 6/7/8 с комментариями по-русски |
| `#/ielts/speaking` | Speaking | Part 1 вопросы-разминка, Part 2 cue card с 60 с подготовки + 120 с ответа, Part 3 вопросы; самооценка; список «полезных связок» |
| `#/plan` | План подготовки | Календарь недели (миссии по дням), фазы до экзамена (шкала), «Пересчитать план», ползунок часов/неделю |
| `#/stats` | Статистика | График прогноза по неделям, тепловая карта активности, мастерство по темам (таблица с сортировкой), время по предметам, точность по типам вопросов |
| `#/settings` | Настройки | Профиль и даты, тема (авто/тёмная/светлая), размер шрифта, экспорт/импорт JSON, «Сбросить прогресс», версия контента |

### 2.2 Навигация

- **Ноутбук:** левый сайдбар 240 px (Сегодня, ЕНТ, IELTS, Повторение, Пробники, План, Статистика, Настройки), контент ≤ 760 px по центру.
- **Телефон:** нижняя панель из 5 вкладок: Сегодня · ЕНТ · Повтор · IELTS · Ещё (План, Статистика, Настройки). В практике и пробнике нижняя панель скрывается — экран целиком под вопрос.

### 2.3 Что НЕ входит в v1

Аккаунты, синхронизация, проверка эссе ИИ, запись аудио, казахский интерфейс, форум, «умная» адаптивность по IRT, уведомления. Все они не нужны, чтобы первый ученик получил пользу в первый день.

## 3. Учебный цикл

### 3.1 Сессия по минутам (стандартная миссия «Новая тема», 25 мин)

| Мин | Что происходит | Экран |
|---|---|---|
| 0–1 | Открывает «Сегодня», нажимает «Начать» на миссии «Математика · Квадратные уравнения · 25 мин» | `#/` → `#/topic/…` |
| 1–8 | Читает теорию: 3–5 блоков, ≤ 700 слов, 1–2 разобранных примера; в середине — блок «Проверь себя» с одним вопросом (не влияет на мастерство, только фиксирует `theoryRead`) | `#/topic/…` |
| 8–9 | «Перейти к практике» — фокус-режим | `#/practice/…` |
| 9–20 | 10 вопросов (7 одиночных + 3 мультиответ, если тема профильная). После каждого ответа — разбор: верный ответ, объяснение, «почему другие неверны». Вопрос с ошибкой автоматически становится SRS-карточкой | `#/practice/…` |
| 20–23 | «Исправь ошибки»: неверные вопросы задаются ещё раз (вариант с другими числами, если у вопроса есть `variantOf`, иначе тот же) | `#/practice/…` |
| 23–24 | Итог: мастерство 0 → 58, +120 XP, серия 6 дней, «В повторении +3 карточки» | модалка итога |
| 24–25 | Возврат на «Сегодня»: миссия отмечена, следующая — «Повторение · 8 мин» | `#/` |

Миссия «Повторение» (5–10 мин): очередь SRS. Миссия «IELTS» (10–15 мин): 10 новых слов **или** один passage/section. Миссия «Пробник» (сб): мини или полный.

### 3.2 Цикл теория → практика → ошибки → повтор

```
теория (theoryRead=true)
  → практика 10 вопр.  → attempt-лог
      → ошибки          → SRS-карточка (box 0, due = завтра)
      → «Исправь ошибки» (сразу, не влияет на SRS)
  → SRS-очередь на #/review каждый день
      → правильно: box+1, due = today + interval[box]
      → неверно:   box = 0, lapses+1, due = завтра
  → тема с mastery ≥ 80 получает статус «освоена»
  → если retention R падает ниже 0.75 → статус «требует повтора», план ставит миссию «Повтор темы» (5 вопросов)
```

Интервалы SRS (модифицированный Лейтнер): `[1, 3, 7, 14, 30, 60, 120]` дней. «Сложно» = остаться в боксе, due = today + interval[box]/2.

### 3.3 Мастерство темы (0–100)

Для темы `t` храним: список последних попыток (`ok ∈ [0,1]`, для мультиответа доля баллов), множество увиденных вопросов, `lastAt`, `stability`.

```
A  (точность с забыванием старых попыток и байесовской усадкой к 0.5):
    w_i = 0.85^i          (i = 0 для самой свежей попытки, берём последние 30)
    A   = (Σ w_i·ok_i + 2·0.5) / (Σ w_i + 2)

C  (покрытие пула вопросов):
    C   = min(1, seenDistinct / min(poolSize, 15))

R  (удержание — сколько помнит с последнего контакта):
    R   = 0.6 + 0.4 · exp(−daysSinceLast / stability)
    stability: старт 3 дня; после каждой сессии с точностью ≥ 0.8 → ×2.2 (макс 90); после сессии < 0.5 → ÷2 (мин 2)

mastery_t = round(100 · A · C · R)
```

Пороги: `< 40` красный «слабая», `40–79` жёлтый «изучаю», `≥ 80` зелёный «освоена». Вопросы из пробников тоже пишутся в attempt-лог темы (с `mode: "mock"`), так что пробник обновляет мастерство.

### 3.4 Прогноз ЕНТ (из 140)

Чертёж экзамена задаёт `maxPoints` предмета и вес каждой темы `weight_t` (сколько вопросов ЕНТ приходится на тему).

```
M_s   = Σ_t (weight_t · mastery_t) / Σ_t weight_t / 100        — мастерство предмета 0..1
E_s   = EWMA (α = 0.5) по последним 3 пробникам: score_s / max_s  — эмпирика
n_s   = число пробников с этой секцией (полных или мини)

P_s   = n_s = 0 : max_s · 0.85 · M_s
        n_s ≥ 1 : max_s · ( (0.4 + 0.2·min(n_s,3)/3) · E_s  +  (0.6 − 0.2·min(n_s,3)/3) · M_s )
                  (при 3+ пробниках: 0.6·E_s + 0.4·M_s)

Прогноз ЕНТ = round( Σ_s P_s ),   s ∈ {история, матграм, чтение, математика, информатика}
Погрешность  = ± max(5, 15 − 3·n_mocks_full)
```

Показываем «94 ± 9», при ≥ 4 полных пробниках — «94 ± 5». Дашборд хранит еженедельный снимок для графика.

### 3.5 Прогноз IELTS (band)

```
Listening / Reading: raw (0..40) → band по официальной таблице (content/ielts/bands.json),
                     берём EWMA (α = 0.5) последних 3 тестов; без тестов — «—»
Writing:  среднее 4 критериев самопроверки (TA/TR, CC, LR, GRA), по последним 3 работам,
          ограничение: не выше 7.0 без внешней проверки (помечаем «самооценка»)
Speaking: среднее самооценки по 4 критериям (FC, LR, GRA, P), не выше 7.0

Overall = округление по правилу IELTS среднего 4 band:
          дробная часть < .25 → вниз; .25–.74 → .5; ≥ .75 → вверх
Если оценён хотя бы 1 навык — показываем «предварительно ~6.0», если все 4 — «6.5 (самооценка W/S)»
```

## 4. Модуль пробного экзамена

### 4.1 Формат (по чертежу `content/blueprints/ent-2026.json`)

Структура вынесена в JSON, потому что формат ЕНТ меняется; при изменении правим один файл.

| Секция | Вопросов | Тип | Баллы |
|---|---|---|---|
| История Казахстана | 20 | одиночный (A–E) | 1 × 20 = 20 |
| Математическая грамотность | 10 | одиночный | 1 × 10 = 10 |
| Грамотность чтения | 10 | одиночный, по 2–3 текстам-контекстам | 1 × 10 = 10 |
| Математика | 35 | 20 одиночных + 15 «один или несколько из 8» (A–H) | 20 + 2 × 15 = 50 |
| Информатика | 35 | 20 одиночных + 15 «один или несколько из 8» | 50 |
| **Итого** | **110** | | **140**, 240 минут |

**Подсчёт мультиответа (правило ЕНТ):**

```
errors = |правильные \ выбранные| + |выбранные \ правильные|
points = errors == 0 ? 2 : errors == 1 ? 1 : 0
```

Одиночный: 1 балл за точное совпадение. Пустой ответ = 0, штрафа нет (показываем это в подсказке перед стартом — «отвечай на всё»).

### 4.2 Сборка варианта

Для каждой секции: берём темы предмета, для каждой темы `weight_t` вопросов, выбираем случайно из пула с исключением вопросов, отвеченных в последних 2 пробниках; для мультиответа — только вопросы `type: "multi"`. Если пула не хватает — добираем из соседних тем и помечаем вариант «неполный чертёж» (честно). Seed сохраняется в попытке — вариант воспроизводим.

### 4.3 Интерфейс прохождения

- Таймер общий на весь экзамен (как в реальном ЕНТ), в хедере, красный на последних 15 минутах. Пауза недоступна в полном режиме, доступна в мини.
- Панель навигации: 5 вкладок-секций, под ними сетка номеров: серый — не отвечен, синий — отвечен, жёлтая точка — помечен.
- Свободное перемещение между секциями (как на реальном ЕНТ), кнопка «Завершить экзамен» с подтверждением «Не отвечено: 7».
- Каждый ответ пишется в localStorage сразу — закрыл вкладку, вернулся через `#/mock/run/:id`, таймер продолжает считать от `startedAt` (без «читерской» паузы).
- Клавиатура: 1–8 выбор, `M` пометить, `←/→` вопрос, `Enter` далее.
- В мультиответе показываем «выбрано 2» — ученик должен привыкнуть, что верных может быть от 1 до 3+.

### 4.4 Результат

Балл /140 крупно, под ним цель (например, 120) и предыдущий пробник. Таблица по секциям: балл, %, время. Список вопросов с фильтром «неверные»; каждый разворачивается в разбор. Все неверные автоматически уходят в SRS (карточки типа `question`). Кнопка «Тренировать слабые темы этого пробника» → формирует миссии на неделю.

### 4.5 Мини-режимы

| Режим | Состав | Время |
|---|---|---|
| Мини по предмету | 10 вопросов предмета по чертежу пропорционально (для профильных 6 + 4 мульти) | 15 мин (профильные 20) |
| Экспресс-ЕНТ | 30 вопросов: 5 ист + 3 матграм + 2 чтение + 10 мат + 10 инф (пропорция чертежа) | 55 мин |
| Полный | 110 вопросов | 240 мин |

Мини-результаты тоже идут в `E_s` (с весом 0.5 против 1.0 у полного) — так прогноз живёт, даже если полный пробник только раз в 2 недели.

## 5. Модуль IELTS Academic

Ограничение: без бэкенда нельзя записывать аудио и проверять эссе. Решение — авто-проверка там, где ответ формальный (L/R/словарь), и **структурированная самопроверка** там, где нет (W/S), с образцами и рубриками на русском.

### 5.1 Listening

- Контент: `content/ielts/listening/s01.json` — ссылка на аудио (YouTube-embed через iframe или mp3 по ссылке), 10 вопросов секции (form completion, MCQ, map labeling через нумерованную картинку), транскрипт.
- Практика: одно прослушивание, ответы вводятся по ходу; после проверки — транскрипт с подсветкой мест ответов и русским пояснением ловушек («говорящий сначала называет 15, потом исправляет на 50»).
- Тренировка навыка, а не только теста: «диктанты чисел/дат/имён» — 20 коротких заданий по правописанию (типичная потеря баллов).

### 5.2 Reading

- Passage (700–900 слов) + 13–14 вопросов всех типов: True/False/Not Given, Yes/No/Not Given, matching headings, matching information, sentence completion, MCQ, summary completion.
- Двухпанельный экран с независимой прокруткой; на телефоне — вкладки «Текст / Вопросы» с плавающей кнопкой переключения.
- Таймер 20 мин на passage (реальная норма). После проверки: каждое объяснение указывает абзац и цитату, разбирает *почему Not Given, а не False* — самая частая ошибка русскоязычных.
- Теория: 6 коротких уроков (по типу вопросов) с русскими объяснениями и мини-практикой 5 вопросов.

### 5.3 Writing

- Task 1 (график/таблица/процесс — картинка в контенте) и Task 2 (essay). Таймер 20/40 мин, редактор с живым счётчиком слов и предупреждением «< 150 / < 250».
- После «Сдать»: **рубрика самопроверки** — 4 критерия × 5 конкретных да/нет-вопросов на русском (например, CC: «Есть ли в каждом абзаце одна главная мысль?», «Использованы ли ≥ 3 разных связки, не только however?»). Из ответов считается band критерия (5.0–7.0), суммарно — band работы.
- Рядом — 3 образца (band 6 / 7 / 8) на это же задание с русскими пометками на полях, и «чек-лист структуры» для Task 2.
- Все работы сохраняются в localStorage (текст + рубрика) — ученик видит рост словарного запаса и структуры; экспортом можно отправить учителю.
- Теория: 8 уроков (структура Task 1/2, линкеры, паттерны для графиков, типичные ошибки русскоязычных: артикли, порядок слов, «very» вместо академической лексики).

### 5.4 Speaking

- Part 1: банк 60 вопросов по 12 темам, показываются по 4, таймер 30 с на ответ (говорит вслух).
- Part 2: cue card (тема + 4 пункта), 60 с подготовки (поле для заметок), 120 с ответа с индикатором; после — модельный ответ с подсветкой связок и «идей, которые можно переиспользовать».
- Part 3: 3–4 абстрактных вопроса по теме, подсказки-«скелеты» ответа (Opinion → Reason → Example → Contrast).
- Самооценка 4 критерия по шкале 5.0–7.0 с подсказкой «как понять, что у тебя 6, а не 7».
- Опционально: кнопка «записать» через `MediaRecorder` для прослушивания *самого себя* (локально, не сохраняется) — это работает без бэкенда и очень полезно; в v1 помечено как «эксперимент».

### 5.5 Словарь с интервальным повторением

- 20 тематических наборов по 30 слов (600 слов на band 6.5–7): слово, часть речи, транскрипция, перевод, определение на английском, пример из академического контекста, коллокации.
- «Учить новые» — 10 карточек: показ → «Знаю / Не знаю»; неизвестные сразу входят в SRS (box 0).
- «Повторять» — общая SRS-очередь с двумя направлениями (en→ru узнавание, ru→en воспроизведение с вводом слова и мягкой проверкой по расстоянию Левенштейна ≤ 1).
- В IELTS-хабе: «Активный словарь: 214 слов (box ≥ 3)» — эта метрика идёт в оценку LR при самопроверке письма как подсказка.

## 6. План подготовки

### 6.1 Входные данные

- `entDate` (по умолчанию 2028-06-01), `ieltsDate` (может быть пустой), `hoursPerWeek` (по умолчанию 7).
- Шаблон доступности «2-я смена»: Пн–Пт: утро 60 мин (10:00–11:00), вечер 30 мин (20:30–21:00); Сб: 120; Вс: 90. Итого ≈ 10 ч — пользователь ужимает ползунком до своих 6–8 ч; минуты дней масштабируются пропорционально.
- Текущее мастерство тем, SRS-очередь, дата последнего пробника.

### 6.2 Алгоритм (пересчёт каждое утро и по кнопке)

```
1. weeksToEnt = (entDate − today) / 7
   phaseEnt = weeksToEnt > 40 ? "foundation"
            : weeksToEnt > 8  ? "consolidation"
            : "exam"

2. Доля IELTS:
   shareIelts = ieltsDate пусто ? 0
              : weeksToIelts ≤ 12 ? 0.5
              : weeksToIelts ≤ 30 ? 0.35
              : 0.25

3. Минуты недели: W = hoursPerWeek·60
   W_review = min(0.15·W, 10 мин · 7)          — SRS фикс
   W_ielts  = shareIelts · (W − W_review)
   W_ent    = W − W_review − W_ielts

4. Распределение W_ent по предметам:
   weight_s   = maxPoints_s / 140            (история .14, матграм .07, чтение .07, мат .36, инф .36)
   deficit_s  = 1 − M_s                       (M_s из §3.4)
   priority_s = 0.10 + weight_s · deficit_s   (0.10 — пол, чтобы никто не «умер»)
   minutes_s  = W_ent · priority_s / Σ priority

5. Очередь тем предмета (topicQueue_s):
   а) темы со статусом «требует повтора» (R < 0.75)          → миссия «Повтор темы», 10 мин
   б) незавершённые темы (mastery < 80), prereq выполнены,
      сортировка: weight_t desc, затем mastery asc            → миссия «Новая тема», 25 мин
   в) если все ≥ 80 → «Сложные задачи», 15 мин
   В фазе "exam" пункт (б) заменяется на «Слабые темы»: mastery < 60 сначала.

6. Раскладка по дням (жадно):
   для каждого дня d с бюджетом B_d:
     если SRS due > 0            → миссия «Повторение», min(10, 1.5·due) мин
     пока B_d ≥ 15:
       предмет = argmax по (minutes_s − already_s)  среди ЕНТ и «ielts» как псевдопредмета с бюджетом W_ielts
       снять следующую миссию из очереди предмета, если влезает
     суббота: «Пробник»
       foundation:    мини по слабейшему предмету (15–20 мин) каждую неделю
       consolidation: экспресс-ЕНТ (55 мин) каждую неделю, полный — раз в месяц
       exam:          полный ЕНТ (240 мин) каждую 2-ю субботу, экспресс — в остальные
     IELTS-миссии чередуются: словарь(10) → reading(25) → listening(20) → writing(45, только Сб/Вс) → speaking(15)

7. День = массив миссий, каждая:
   { id, kind: "topic"|"review"|"repeat"|"hard"|"mock"|"ielts-vocab"|"ielts-reading"|…,
     ref (topicId / blueprintId / passageId), minutes, status: "todo"|"done"|"skipped" }
```

Правила устойчивости: пропущенная миссия не «копится» (никакого долга), а просто возвращается в очередь — план на завтра пересчитывается. Ученик может вручную поменять миссию местами или «выполнить другую тему» — план принимает факт.

### 6.3 Экран `#/plan`

Верх: шкала до ЕНТ с фазами и точкой «сейчас», рядом до IELTS. Середина: неделя сеткой Пн–Вс, в ячейке — миссии с минутами; выполненные — зачёркнуты. Низ: ползунок «часов в неделю», переключатель «IELTS: да/нет», кнопка «Пересчитать».

## 7. Система мотивации

Тон: спортивный трекер, не детская игра. Никаких конфетти и мультяшек; цифры, дельты, серии.

| Механика | Правило |
|---|---|
| **Серия дней** | День засчитан, если выполнена ≥ 1 миссия или ≥ 10 мин активности. За 7 дней подряд выдаётся 1 «заморозка» (макс 2 в запасе) — пропуск дня не рвёт серию. Показываем «Серия 12 · лучшая 23» |
| **XP** | Верный ответ в практике 10, в повторении 5, в пробнике 3/балл; завершение темы (mastery ≥ 80 впервые) 150; полный пробник 300, экспресс 120, мини 50; IELTS passage/section 80, writing со сдачей рубрики 120, 10 новых слов 30. Ежедневный бонус «все миссии дня» +50 |
| **Уровни** | `level = floor(sqrt(XP / 250)) + 1`; названия уровней 1–10: Абитуриент → … → Дайын. Полоса до следующего уровня на дашборде |
| **Бейджи (14)** | «Первый пробник», «Сотня» (100 верных подряд не обязательно — 100 верных всего), «Без ошибок» (10/10 в практике), «Мульти-мастер» (10 мультиответов подряд на 2 балла), «7 дней», «30 дней», «Полуфинал» (прогноз ≥ 70), «Сотня баллов» (прогноз ≥ 100), «Марафон» (полный пробник до конца), «Реадер» (10 passages), «600 слов», «Историк» (история ≥ 80 по всем темам), «Ранняя пташка» (5 утренних сессий до школы), «Честный» (сдал 5 writing с рубрикой) |
| **Недельный отчёт** | В воскресенье на дашборде карточка: минуты, XP, темы завершены, прогноз ЕНТ было → стало, лучший/худший предмет, «фокус следующей недели: Информатика — 3 слабые темы». Кнопка «Сохранить как картинку» не нужна в v1 — достаточно, что карточку можно заскринить: она сделана как shareable-плитка |

## 9. Визуальное направление

**Характер:** спокойный, «инструментальный», как трекер тренировок или терминал брокера — цифры главнее декора. Ученик занимается в 21:00 после школы, поэтому **тёмная тема — основная**, светлая — вторая, переключение авто по `prefers-color-scheme`.

### 9.1 Цвета (CSS-переменные)

| Токен | Тёмная | Светлая | Роль |
|---|---|---|---|
| `--bg` | `#0F1115` | `#F7F8FA` | фон страницы |
| `--surface` | `#181B22` | `#FFFFFF` | карточки |
| `--surface-2` | `#20242D` | `#EEF0F4` | вложенные блоки, варианты ответа |
| `--text` | `#E8EAF0` | `#151820` | основной текст |
| `--muted` | `#8B92A5` | `#5F6678` | подписи |
| `--accent` | `#5B8CFF` | `#2F6BFF` | ЕНТ, кнопки, ссылки |
| `--accent-2` | `#22C3A6` | `#149E86` | IELTS |
| `--ok` / `--warn` / `--bad` | `#3DDC97` / `#F5B84A` / `#FF6B6B` | `#1DA870` / `#D9930F` / `#E04848` | мастерство, ответы |
| `--ring-track` | `#2A2F3A` | `#E1E4EA` | пустое кольцо |

Предметы отличаются только тонким цветным индикатором слева на карточке (история — янтарный, матграм — фиолет, чтение — розовый, математика — синий, информатика — циан), а не заливкой.

### 9.2 Типографика

- Текст: **Inter** (Google Fonts, кириллица), fallback `system-ui`. 16 px на телефоне, 17 px на ноутбуке, `line-height 1.55`.
- Цифры (баллы, таймер, XP): Inter с `font-variant-numeric: tabular-nums` — цифры не «прыгают».
- Код (информатика): **JetBrains Mono**.
- Формулы: KaTeX, `\displaystyle` для выделенных блоков, inline в тексте вариантов.
- Шкала: 13 / 15 / 17 / 20 / 24 / 32 / 48 (48 — только для прогнозного балла).

### 9.3 Сетка и мобильный layout

8-px сетка, радиус карточек 14 px, тени почти нет (в тёмной теме — только границы `1px var(--surface-2)`). На телефоне: одна колонка, карточки во всю ширину с отступом 16 px, нижняя навигация 56 px с safe-area. Варианты ответа — крупные тап-зоны ≥ 48 px, вся строка кликабельна. Двухпанельный Reading превращается во вкладки. Таймер пробника — sticky сверху.

### 9.4 Пять деталей, которые делают «премиум»

1. **Кольцо мастерства с дельтой.** SVG-кольцо на карточке темы анимирует дугу от старого к новому значению (400 мс, ease-out) при возврате из практики, а сверху всплывает «+14». Один и тот же компонент везде — в списке тем, в итоге сессии, в отчёте.
2. **Ответ без театра.** Верный вариант — галочка «дорисовывается» за 180 мс, фон мягко зеленеет; неверный — короткое смещение на 2 px и красная рамка, верный при этом подсвечивается. Никаких конфетти, звук выключен по умолчанию.
3. **Клавиатура как первый класс.** 1–8 выбирает вариант, Enter — ответить/дальше, `T` — открыть теорию темы в боковой панели, `M` — пометить, `Esc` — выйти из фокус-режима. Подсказка клавиш появляется один раз и живёт в «?».
4. **Ноль пустых экранов.** Каждое состояние «пока нет данных» — конкретное действие: «Прогноз появится после первой практики — начни с “Квадратные уравнения”, 25 мин». Скелетоны при загрузке JSON вместо спиннеров; переход по hash без мерцания (старая страница остаётся до готовности новой).
5. **Честные цифры.** Прогноз всегда с погрешностью («94 ± 9»), самооценка W/S помечена, «мастерство» подписано датой последнего контакта («освоена · 12 дней назад · начинает забываться»). Ученик доверяет цифрам, потому что они не льстят.

## 10. Путь роста (когда он начнёт делиться сайтом)

Порядок — по соотношению «ценность / стоимость», с сохранением статики на фронте.

| Шаг | Что | Как без переписывания |
|---|---|---|
| 1. PWA | Работа офлайн, иконка на телефоне | `manifest.json` + service worker, кэш `content/` по `version` |
| 2. Аккаунты + синхронизация | Вход через Google/e-mail, прогресс на всех устройствах | Supabase Auth + одна таблица `progress(user_id, json, updated_at)`; `store.js` получает второй бэкенд с merge по `updatedAt` на уровне разделов (`topics`, `srs`, …), localStorage остаётся кэшем |
| 3. Лидерборды и «классы» | Недельный рейтинг по XP среди друзей по коду класса, без публичных прогнозов баллов | Таблица `groups` + view недельного XP; клиент читает один запрос |
| 4. Режим учителя | Учитель видит мастерство по темам своих учеников, назначает тему/пробник | Роль в Supabase, страница `#/teacher`, назначение = запись миссии в план ученика |
| 5. Казахский язык | UI-строки в `i18n/kk.json`, контент в `content/kk/` с тем же индексом; переключатель на онбординге | Все строки UI уже через `t('key')` с первого дня; контент — параллельная папка |
| 6. Сообщество контента | Сообщение об ошибке в вопросе, предложения правок | Кнопка «Сообщить» → Supabase таблица `reports`; ревью — вручную |
| 7. Проверка эссе и Speaking ИИ | Оценка Writing по официальной рубрике, транскрипт Speaking | Edge-функция с LLM; интерфейс рубрики уже есть — заменяется только источник оценки |
| 8. Напоминания | Telegram-бот «сегодня 3 миссии, 40 мин» | Бот читает план из Supabase, шлёт в 19:30 |
| 9. Адаптивность | Подбор сложности вопросов по Эло-рейтингу | Поле `difficulty` уже есть; добавляется рейтинг ученика в `topics[t]` |

Ключевое решение, которое делает всё это возможным без переписывания: **один версионированный JSON прогресса** и **контент, отделённый от кода**. Синхронизация — это тот же объект в облаке; казахский — та же схема в другой папке; учитель — чтение чужого объекта.

## 11. Порядок сборки v1 и минимальный контент

### 11.1 Этапы (каждый даёт рабочий сайт)

1. **Каркас (неделя 1):** роутер, store с экспортом/импортом, тема ЕНТ (теория + практика + разбор), mastery, дашборд с прогнозом, `start.bat`.
2. **Цикл (неделя 2):** SRS-повторение, план и миссии, streak/XP, онбординг, предметы и хабы.
3. **Пробник (неделя 3):** чертёж, сборка варианта, прохождение с таймером, результат, мини/экспресс.
4. **IELTS (неделя 4):** словарь + SRS, Reading, Listening, Writing с рубрикой, Speaking, band-таблица, прогноз band.
5. **Полировка (неделя 5):** статистика, недельный отчёт, тёмная/светлая тема, мобильный режим, клавиатура, пустые состояния.

### 11.2 Контент для «дня один»

| Раздел | Минимум для запуска | Цель через 3 месяца |
|---|---|---|
| История Казахстана | 4 темы × 15 вопросов + 40 карточек-фактов | 24 темы |
| Мат. грамотность | 3 темы × 15 | 8 тем |
| Грамотность чтения | 3 текста × 5 вопросов + 1 урок «как читать задание» | 15 текстов |
| Математика | 5 тем × 20 (≥ 6 multi) | 30 тем |
| Информатика | 4 темы × 20 (≥ 6 multi) | 25 тем |
| IELTS | 3 набора слов (90), 2 reading, 2 listening, 2 writing (T1+T2) с образцами, 10 cue cards, 4 урока | 20 наборов, 12 reading, 8 listening, 10 writing, 40 cards, 14 уроков |

Этого хватает, чтобы полный пробник собирался (с пометкой «неполный чертёж» по некоторым секциям), а план заполнял 2–3 недели миссий.
